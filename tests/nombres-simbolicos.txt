# Los nombres que las aplicaciones de VasakOS piden como icono simbólico.
#
# El plugin de iconos del escritorio resuelve con FORCE_SYMBOLIC, y GTK con esa
# bandera busca «<nombre>-symbolic» a lo largo de **toda** la cadena de herencia
# antes de probar el nombre pelado. O sea que si el pack tiene
# `actions/16/view-split-left-right.svg` pero no
# `actions/symbolic/view-split-left-right-symbolic.svg`, el icono no sale de acá:
# sale de breeze, que dibuja en #232629 y queda invisible sobre el tema oscuro.
#
# Cada nombre de esta lista tiene que resolverse **dentro** del pack y ser
# legible en las dos variantes. Lo verifica `verificar-simbolicos.py`.
#
# Sembrada desde vasak-file-manager, que es la aplicación con el vocabulario de
# barra de herramientas más grande. Al auditar otra aplicación, sumar acá los
# nombres que pida.
